Questions

Do my files get uploaded?

No. FileReady reads, fixes and builds PDFs on the device you are using. There is no account and no server.

Which rules does it know?

All 50 states, D.C., federal courts and the USPTO, plus data-protection flags for eight regions. Each rule pack links to its official source and shows when it was last reviewed.

Is this legal advice?

No. FileReady flags common problems and prepares documents. Lawyers stay in charge: confirm your court's current rules, local rules and any judge's standing orders.

How does redaction work?

A redacted page is redrawn as an image with the marked areas blacked out, so the hidden text is gone. The rest of the page keeps an invisible text layer so it stays searchable.

What does it run on?

Android as an installable app, and any modern browser on a computer. It works offline once loaded.

Who built it?
